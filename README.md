# Rotating Cube - DirectX 11 Demo

A simple 3D rotating cube demonstration built with C++ and DirectX 11, featuring custom mathematics implementation and interactive controls.

![Cube](https://github.com/user-attachments/assets/24a4009c-b120-4ba6-96fa-ca459b40889d)

## Features

- **3D Cube Rendering** - Textured cube with custom vertex and index buffers
- **Custom Math Implementation** - Hand-written matrix and vector mathematics without DirectXMath
- **Real-time Rotation** - Interactive cube manipulation via mouse input
- **Dynamic Scaling** - Mouse wheel zoom with adjustable scale factor
- **Stationary Camera** - Fixed perspective view for consistent visualization
- **Pre-defined Colors** - Simple vertex colors without dynamic lighting
- **DirectX 11 Pipeline** - Modern graphics API with custom math layer

## Technical Highlights

- **Custom Mathematics Library** - Hand-coded matrix operations, vector math, and transformation functions
- **No DirectXMath Dependency** - Pure custom implementation of 3D graphics mathematics
- **Simple Color System** - Pre-defined vertex colors for clean visualization

## Controls

- **Mouse Drag** - Rotate the cube in 3D space
- **Mouse Wheel** - Zoom in/out (scale the cube)
- **UI Controls** - Adjust scale and rotation factor 

## Building

### Requirements
- DirectX 11 compatible GPU

## Educational Value

This project demonstrates:
- **3D Graphics Mathematics** - Custom implementation of transformation matrices
- **DirectX 11 Fundamentals** - Buffer management and rendering pipeline
- **Manual Math Operations** - Matrix multiplication, vector operations without libraries
- **Real-time 3D Interaction** - Mouse-based object manipulation

## Custom Math Features

- Hand-written 4x4 matrix operations
- Custom vector mathematics (3D and 4D)
- Transformation matrices (rotation, scale)
- Perspective projection implementation
